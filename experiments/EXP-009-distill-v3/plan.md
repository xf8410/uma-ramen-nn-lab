# EXP-009 立项：蒸馏 v3——收种子方差 + 状态分布对齐，目标 70000

## 起点（EXP-008b 裁决后盘面）

- NN 3 种子：65006.9 / 64892.4 / **65669.2（超手写冠军 ✅）**，均值 65189.5
- 距 70000：均值 −4810，最好种子 −4331
- **种子散布 ~550 分是当前最大可控损耗**：0832 已证标签配方上限 > 手写冠军，0830/0831 输在训练方差而非配方上限

## 本轮三个变量（对照 EXP-008，一次全上——归因靠臂内对照）

### 变量 A：数据 78k → 160k（收方差主力）

- EXP-008 的 12k 对照=108.4 vs 全量=89.6：数据量效应仍显著（−18.8）
- 80 分片 × 2000 条 = 160000，index [0,160000)，与 008 的 [0,80000) **前 80k 区间完全重合**（sample_position 确定性）——即本轮数据集是 008 的超集，可直接复用 008 已采分片的结论做 assemble 校验
- 预算：~2.5h（008 是 1.5h/80k）

### 变量 B：训练配方（收方差异化种子）

- epochs 200 → 400、早停 patience 加长（008 三个种子分别停在 45/35/72 ep，全都没到 200 上限——说明还没收敛到方差钉死，数据更多+更久可能拉齐）
- 其余（模型结构、切分、学习率）不动——结构消融被 PRINCIPLES 禁

### 变量 C：采样器轨迹策略换冠军（状态分布对齐强教师）

- 现状：状态分布来自默认策略世界（采样器 trajectory），评估却用冠军——标签是"冠军在'普通世界'的决策"
- 换法：SamplerConfig 无策略钩子，**上游采样器不注入教师策略** → 本轮放弃 C（要改上游 sampler，超出 patch 预算），转由变量 A 的 index 扩张部分替代（新 index 覆盖更多样的局面）
- 记账如实：C 缺席，状态分布仍是默认世界

## 工作流（exp-009.yml，结构 = exp-008.yml 改三处）

1. collect：80 分片 × CHUNK=2000（run.sh 已支持 CHUNK 参数）
2. assemble：区间断言 [i*2000,(i+1)*2000)，总量 160000
3. convert + labels：同 008
4. train 矩阵：3 种子 × {全量, --epochs 400}（对照臂保留 12k 抽稀，共 4 job）
5. summary：健康性（regret 散布收窄是本轮 Python 侧的核心观察量）

## 裁决（EXP-009b，同 008b 口径）

- NN 3 种子 × 双口径（手写默认 65438.2 / 冠军 65554.2），配对 t>2 且 Δ>0
- **本轮成功判据**：3 种子全部超默认 + 均值 ≥65554（贴齐冠军）
- 70000 判据：需要新量级的跃迁（regret ~30 档或教师本身再上 70000 档），本轮不承诺，过线另立 EXP-010

## 风险与止损

- 160k 训练单 job 可能超 300min timeout：预设 `--epochs 400` 与 4 job 并行在免费额度内（20 并发上限远未触）
- 若 3 种子仍散布 >300：下一轮单变量隔离训练配方（把 A/B 拆开归因）
