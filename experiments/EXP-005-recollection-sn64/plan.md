# EXP-005：正式重采（search_n=64 × 80000 条）

## 假设 H5
标签质量（rollout 列数）+ 数据量同时升级后，Python 留出 regret 从 309.7 显著回落（目标 ≤200，理想 ~150 量级）；回落幅度可用 EXP-004 标定的映射（35–60 闭环分/regret 点）预估闭环收益，达阈值即进 EXP-004b 闭环复裁决。

## 依据
- EXP-003b：H3b 证实——sn8 教师选择稳定率 0.832 vs pilot ~0.99；剂量响应成立；**pilot 实为 search_n=512**
- EXP-004：闭环裁决管线全自动（8 分钟/轮），手写 8rep=65009.7 与锚点一致
- 数据量：上游 DESIGN 规划正式数据 8 万条（"8 万条到齐后自动重算归一化常数"）

## 配置

| 项 | 值 | 依据 |
|---|---|---|
| search_n | **64** | sn32/sn64 均过 10% 判定线；64=8×当前，成本可控；若 regret 仍>200 下一轮 128（矩阵改数字） |
| 数据量 | **80000 条**（index [0,80000)，80 分片 × 1000） | 用户裁定"加数量"；DESIGN 8 万条规划 |
| 其余配方 | 与 EXP-002 完全一致（shard 256 / radical 1.4 / quota 20,30‰ / region=all / pin 43f532c） | 唯一变量原则：只动 search_n 与数量 |

## 成本预算（实测外推）
- EXP-002：sn8 ≈ 0.08s/样本 → sn64 ≈ 0.64s/样本 → 1000 条/分片 ≈ 11–16 min
- 80 分片，20 并发 → ~4 波 ≈ **50–70 min** 采集 wall-clock
- convert（80k 导出+标签）≈ 20–40 min；train（80k×3 种子并行）≈ 40–90 min
- 总 wall-clock ≈ **2–3.5h**；全程免费公开 runner
